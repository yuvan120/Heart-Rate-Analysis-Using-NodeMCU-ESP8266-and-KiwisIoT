# Heart Rate Analysis Using NodeMCU ESP8266 and KiwisIoT

## 📌 About the Project

Heart Rate Analysis Using NodeMCU ESP8266 and KiwisIoT is an IoT-based health monitoring project designed to measure and monitor a person's heart rate in real time.

Using a NodeMCU ESP8266 microcontroller and a heart rate sensor, the system detects pulse signals and calculates the heart rate in beats per minute (BPM).

The collected heart rate data is transmitted through Wi-Fi to the KiwisIoT platform, where users can visualize and monitor real-time heart rate readings through an online dashboard.

This project demonstrates how IoT technology can support remote health data monitoring, wearable health applications, and real-time vital sign visualization.

**Note:** This project is intended for educational and demonstration purposes and is not a medical diagnostic device.
